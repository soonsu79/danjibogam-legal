단지보감 개인정보처리방침

시행일: 2026-09-18 · 앱: 단지보감(kr.co.danjibogam.app) · 개발자: HONEY LAB
HONEY LAB(이하 "개발자")이 제공하는 모바일 애플리케이션 "단지보감"(패키지명: kr.co.danjibogam.app, 이하 "본 서비스")은 이용자의 개인정보를 소중히 다룹니다. 본 개인정보처리방침은 본 서비스가 실제로 수집·이용하는 정보의 범위와 방식을 있는 그대로 안내합니다.

1. 수집하는 정보

본 서비스는 회원가입 절차가 없으며, 이름·이메일·전화번호 등 개인을 식별할 수 있는 정보를 입력받지 않습니다. 로그인 없이 누구나 바로 이용할 수 있는 구조입니다.

1-1. 이용자가 직접 입력하는 정보

  • 검색어: 이용자가 검색창에 입력한 아파트 이름 또는 주소입니다. 공동주택 검색 결과를 보여드리기 위해 그때그때 서버로 전송되며, 서버에 영구 저장되지 않습니다.

1-2. 기기에만 저장되는 정보(서버로 전송되지 않음)

  • "저장한 집" 목록: 이용자가 "우리집·부모님집·이사후보"로 분류해 저장한 공동주택 정보(단지 식별값, 단지명, 도로명주소, 분류, 저장 시각)입니다. 이 정보는 이용자의 기기 안(Android SharedPreferences)에만 저장되며, 개발자의 서버나 어떤 외부 서비스로도 전송되지 않습니다. 여기서 저장되는 주소는 이용자 개인의 주소가 아니라 검색한 공동주택 단지의 주소입니다.

2. 자동으로 수집되는 정보

항목IP 주소
수집 방식서비스 요청 시 서버(Supabase Edge Function)가 요청 헤더에서 자동으로 확인
목적짧은 시간 내 과도한 반복 요청(악용·봇)을 걸러내기 위한 요청 빈도 제한 (Rate Limiting)
보관별도 데이터베이스에 저장하지 않고, 서버 메모리에서 최대 1분 단위로만 임시로 유지한 뒤 자동 소멸합니다.

이 외에 기기 식별자, 위치정보, 연락처 등을 본 서비스가 직접 수집하는 절차는 없습니다. 본 서비스가 요청하는 Android 권한은 인터넷 접속 권한(INTERNET) 하나뿐입니다.

3. 이용 목적

  • 검색어 → 조건에 맞는 공동주택 단지를 찾아 검색 결과로 보여드리기 위함
  • 선택한 단지 식별값 → 해당 단지의 참고점수·상세정보를 조회해 보여드리기 위함
  • IP 주소 → 서비스 안정성 유지 및 악용(과도한 반복 요청) 방지
  • "저장한 집" 목록(기기 로컬) → 이용자가 관심 단지를 다시 쉽게 찾아볼 수 있도록 하기 위함

4. 제3자 서비스 및 SDK

본 서비스는 아래 서비스만 실제로 사용합니다. 사용하지 않는 서비스(예: 회원 로그인 SDK, 분석·통계 SDK, 별도 클라우드 저장소 등)는 포함되어 있지 않습니다.

Google AdMob (google_mobile_ads)

화면 하단 배너 광고를 제공하기 위해 사용합니다. AdMob SDK는 광고 제공·측정을 위해 광고 식별자, 기기 정보, 대략적인 위치 등을 Google의 정책에 따라 자체적으로 수집·처리할 수 있습니다. 이는 개발자가 직접 수집하는 것이 아니라 Google의 SDK 자체 동작이며, 자세한 내용은 Google 개인정보처리방침과 AdMob 관련 안내를 참고해 주세요.

Supabase

본 서비스의 서버 기능(검색·조회 API 중계)을 호스팅하는 데 사용합니다. 본 서비스는 Supabase의 데이터베이스에 이용자 정보를 저장하지 않으며, 서버리스 함수(Edge Function)가 아래 공공데이터 API를 중계 호출하는 용도로만 씁니다.

공공데이터포털(data.go.kr) 등 공공기관 API

국토교통부 등이 제공하는 공동주택 기본정보·건축물대장·유지관리 이력 등 공공데이터를 조회하기 위해 서버에서 호출합니다. 이 과정에서 이용자를 식별할 수 있는 정보는 전달되지 않으며, 조회 대상은 공동주택(단지) 정보이지 이용자 개인정보가 아닙니다.

외부 링크

홈 화면의 "공사헌터 보기" 버튼은 외부 웹사이트(gongsahunter.kr)를 기기의 브라우저로 열어줄 뿐이며, 본 서비스가 그 사이트와 이용자 정보를 주고받지 않습니다. 외부 사이트 이용 시에는 해당 사이트의 개인정보처리방침이 별도로 적용됩니다.

5. 보관 및 삭제

  • 서버: 검색어나 이용자를 식별할 수 있는 정보를 서버에 영구 저장하지 않습니다. 요청 처리에 필요한 최소한의 정보만 그때그때 사용되고 즉시 폐기되며, 악용 방지용 IP 카운터도 최대 1분 후 자동 소멸합니다.
  • 기기 로컬("저장한 집"): 이용자가 앱 내에서 언제든 개별 삭제할 수 있고, 앱을 삭제(제거)하면 기기에 남아있던 데이터도 함께 삭제됩니다.

6. 아동의 개인정보

본 서비스는 특정하게 아동을 대상으로 설계되지 않았으며, 회원가입이나 개인정보 입력 절차 자체가 없어 아동으로부터 개인정보를 의도적으로 수집하지 않습니다. 만약 만 14세 미만 아동이 본 서비스를 이용하는 과정에서 개인정보 관련 우려 사항이 있다고 판단되시면 아래 문의처로 알려주시기 바라며, 확인 후 필요한 조치를 취하겠습니다.

7. 이용자의 권리

  • 본 서비스는 별도의 회원 계정이 없어 계정 삭제 절차가 필요하지 않습니다.
  • 기기에 저장된 "저장한 집" 데이터는 앱 안에서 직접 삭제할 수 있으며, 앱 삭제로 전체 데이터를 한 번에 제거할 수 있습니다.
  • 본 서비스의 개인정보 처리에 관해 궁금한 점이나 요청 사항이 있으시면 아래 문의처로 연락해 주시면 확인 후 답변드립니다.

8. 보안

  • 앱과 서버 간 통신은 HTTPS로 암호화됩니다.
  • 공공데이터 API 접속에 필요한 인증키 등은 서버(Supabase Edge Function Secret)에만 보관되며, 앱(클라이언트)에는 포함되지 않습니다.
  • 본 서비스는 꼭 필요한 인터넷 접속 권한(INTERNET) 외의 기기 권한(위치, 저장소, 연락처, 카메라, 마이크 등)을 요청하지 않습니다.

9. 개인정보처리방침의 변경

본 개인정보처리방침은 서비스 변경 사항에 따라 개정될 수 있습니다. 내용이 변경되는 경우 이 페이지를 통해 갱신된 내용을 게시하며, 중요한 변경이 있을 경우 앱 내 공지 등을 통해 안내할 예정입니다.
